# Сколько стоит ваш час

Из желаемого дохода, отпуска и расходов считает честную ставку. Больше не соглашаетесь на первую названную цифру..

## Что где лежит

| Файл | Зачем |
|---|---|
| `product.json` | Манифест: поля, результаты, кейсы, SEO, модель денег. Источник правды. |
| `lib/calc.js` | Расчёт. Чистая функция без DOM и сети — иначе её не проверить. |
| `app.js` | Связка манифеста, расчёта и страницы. Продуктовой логики нет. |
| `index.html` | Страница. Текст под калькулятором — то, чем страница попадает в поиск. |
| `test/calc.test.mjs` | Гоняет `calc()` по кейсам из манифеста. |
| `tools/check.mjs` | Отвечает, продукт это уже или ещё заполненный шаблон. |
| `mobile/tool.dart` | Экран этого продукта в приложении-коробке. |

## Проверка перед сдачей

```bash
npm run gate       # check.mjs + node --test
npm run dev        # http://localhost:8080
```

Обе проверки зелёные и живой адрес отвечает — только тогда работа сдана.

## Выкатка

Пуш в `main` → GitHub Pages раздаёт содержимое корня как есть. Сборки нет,
сторонних сервисов нет.

Продукт живёт в подпапке (`<owner>.github.io/<slug>/`), поэтому все пути
внутри страницы — относительные (`./styles.css`), а не от корня. Путь от
корня увёл бы запрос к соседнему продукту, и сломалось бы это только на
живом адресе. `tools/check.mjs` такие пути ловит.
